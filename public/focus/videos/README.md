# Built-in focus videos

The three bundled offline MP4 assets use these stable paths:

- `focus-1.mp4` — Wasserfall
- `focus-2.mp4` — Regen
- `focus-3.mp4` — Piano

For reliable playback across the supported Tauri webviews, use H.264 video with AAC audio,
preferably at up to 1080p and below 100 MB per file. The display names and paths are defined in
`src/features/focus/lib/videos.ts`.
